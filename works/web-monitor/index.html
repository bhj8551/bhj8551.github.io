Web監視・入力自動化ツール

競合サイトの価格・在庫・新着情報を毎日自動で巡回し、変わったところだけをお知らせする「Web監視」と、CSV の内容を管理画面へ自動で入力・登録する「入力自動化（RPA：パソコン操作の自動化）」をひとつにまとめたツールです。設定は Excel・CSV・設定ファイルで行い、プログラムを書き換える必要はありません。

  • Python
  • Windows 10 / 11・macOS
  • Microsoft Edge・Google Chrome
  • Excel・CSV・Google スプレッドシート出力

こんなお悩みに

  • 競合ショップの価格や在庫を、毎朝ブラウザで1件ずつ確認している
  • 新着の商品・求人・案件・入札情報を見逃したくないが、毎日見に行く時間がない
  • 以前のツールは、サイトのリニューアル後も気づかないまま空の値や間違った値を記録し続けていた
  • ツールが今日もちゃんと動いたのか分からず不安
  • 管理画面への商品登録を、CSV を見ながら1件ずつ手入力している
  • 自動化したいが、プログラムの知識はない。ダブルクリックで動かしたい

できること

1. Web監視（収集 → 変化の検知 → 記録 → 通知）

機能内容
監視対象の管理サイトごとの設定ファイルで URL・ページ送り・取得する項目を指定します。URL の一覧は Excel / CSV でも管理できます。
マナーを守った収集robots.txt の確認、アクセスの間隔（外部サイトは最低1秒）、タイムアウト、失敗時の再試行（待ち時間を倍々に延長）、連絡先入りの User-Agent（アクセス元の名乗り）。
変化の検知前回との違いから、新着・掲載終了・価格変動（前回→今回、変動率）・在庫変化・内容変更を判定します。
履歴の蓄積すべての取得結果と変更履歴をデータベース（SQLite：ファイル1つで動くデータベース）にためます。
出力変更箇所を色分けした Excel（価格・在庫の推移グラフ付き）、CSV（BOM付きUTF-8 / Shift_JIS）、Google スプレッドシート。
通知変化があったときだけ Slack・Chatwork・メール・LINE に通知します。
構造変更の検知取得件数の急な減少や必須項目の欠けを検知すると「構造変更の可能性」を通知し、誤ったデータを比較の基準にしません。
稼働確認実行のたびに日時・件数・エラーを記録します。1日1回の「稼働報告」で、変化がない日も正常に動いていることを確認できます。
JavaScript のページ表示に JavaScript が必要なページも、ブラウザ経由で取得できます（任意）。
詳細ページの取得一覧から各商品の詳細ページをたどり、在庫数・JANコードなどを取得します（1回あたりの上限件数とアクセス間隔を守って取得。任意）。

2. 入力自動化（CSV → 管理画面）

機能内容
未処理の行だけ登録CSV の「ステータス」が「未掲載」（または空欄）の行だけを、ログイン → 入力 → 登録します。
結果の書き戻し成功は「掲載完了」（登録番号・処理日時も記録）、失敗は「エラー（理由）」に更新して CSV を保存します。
テスト実行入力までを行い、登録ボタンは押しません（dry-run）。入力後の画面をスクリーンショットで確認できます。
重複チェック実行前に CSV 内の同じキー（SKU など）の行を見つけて警告し、その行は送信せず「エラー（重複…）」にします（既定で有効）。
途中からの再開1行ごとに保存するため、止まってもそのまま再実行すれば続きから処理します。登録中に中断した行は、二重登録を避けるため要確認にします。
エラー時の記録エラーの画面をスクリーンショットで保存します。連続でエラーになった場合は自動で止まります。
結果の通知完了・エラー・要確認の件数と、エラーの理由（多い順）を Slack・Chatwork・メール・LINE に通知できます（任意）。
確実な待機画面の部品が表示されるまで待ってから操作します（固定の待ち時間に頼りません）。
ブラウザの同梱不要パソコンにインストール済みの Microsoft Edge / Google Chrome をそのまま使います。

ご注意：入力自動化は、お客様ご自身が正当な権限をお持ちのシステム（自社の管理画面や、利用規約で自動操作が認められているサービス）だけを対象とします。

処理の流れ

Web監視

  1. 設定を読み込むサイトごとの設定ファイル・URL一覧（Excel / CSV）
  2. robots.txt を確認許可されていないページは取得せず、エラーとして通知
  3. ページを取得アクセス間隔・再試行・タイムアウトを守って取得
  4. 項目を取り出す商品名・価格・在庫など
  5. 構造チェック件数の急な減少・必須項目の欠けがあれば「構造変更の可能性」を通知し、基準データにしない
  6. 前回との違いを判定新着・価格・在庫・掲載終了
  7. 記録と出力履歴データベース、Excel / CSV / スプレッドシート
  8. 変化があったときだけ通知Slack・Chatwork・メール・LINE。1日1回の稼働報告も

入力自動化

  1. CSV を読み込むステータスが「未掲載」の行だけが対象
  2. 送信前チェック必須・形式・重複。問題のある行は送信せず「エラー（理由）」
  3. ブラウザを起動してログインインストール済みの Edge / Chrome
  4. 1行ずつ入力して登録処理中 → 入力 → 登録
  5. 結果を CSV に書き戻す成功は「掲載完了」と登録番号、失敗は「エラー（理由）」とスクリーンショット
  6. 結果を確認エラーの行を直して再実行すると、その行だけを再処理

マナーと安全対策

Web監視

  • robots.txt で禁止されているページは取得しません（この確認は無効にしないでください）
  • 外部サイトへのアクセス間隔は最低1秒。ページ送りは1つの URL あたり最大200ページまで
  • 失敗時は待ち時間を倍々に延ばして再試行し、相手のサイトに負担をかけません
  • 構造変更の可能性があるときは、その回のデータを比較の基準にしません
  • 1日1回の稼働報告で、止まっていないかを確認できます

入力自動化

  • テスト実行（登録ボタンを押さずに入力まで）で、事前に入力内容を確認できます
  • 送信前に必須項目・形式・重複をチェックします
  • 登録中に中断した行は、二重登録を避けるため「要確認」にします
  • 連続でエラーになったら自動で止まります（画面の変更や障害の可能性）
  • ログイン情報は設定ファイルとは別のファイル（.env）に保存します

導入の流れ

  1. ヒアリング

    監視したいサイト・項目・頻度、入力したい画面と CSV の内容、通知先をお伺いします。

  2. 事前確認

    対象サイトの利用規約と robots.txt、管理画面の操作権限を確認します。

  3. 設定・試験運用

    サイトと入力の設定を作り、テスト実行で結果をご確認いただきます。

  4. 納品・操作説明

    お客様のパソコンへのセットアップ、定期実行の登録、操作方法のご説明を行います。

  5. 運用・保守

    納品後2週間は不具合に対応します。構造変更への対応や監視対象の追加は、必要に応じてご相談ください。

項目内容（例）

保守の範囲・頻度は、対象サイトの数や更新の頻度に応じて個別にご相談させてください。

対応しないこと・注意点

このツールは、Webサイトの運営者と利用規約を尊重した利用を前提としています。次のことには対応いたしません。

  • CAPTCHA（ロボットでないことの確認）・ログイン制限・IP制限など、アクセス制限の回避
  • 利用規約で禁止されている収集、および許可なく会員限定ページを収集すること
  • 過度な高頻度アクセス（外部サイトへのアクセス間隔は最低1秒、ページ送りは1つの URL あたり最大200ページに制限しています）
  • 自動購入・自動入札・予約枠の自動確保などの取引の自動化
  • 正当な権限のないシステムへの自動入力（入力自動化は、お客様が操作権限をお持ちのシステムに限ります）

robots.txt で禁止されているページは取得しません。収集した情報の利用は、著作権法・個人情報保護法などの関連法令に従ってください。サイトのデザインが変わった場合は、設定の修正が必要になることがあります。

よくある質問

どんなサイトでも監視できますか？

利用規約と robots.txt で自動での取得が認められているページが対象です。導入前に確認し、認められていないサイトはお引き受けしません。表示に JavaScript が必要なページにも対応しています。

毎日自動で動かせますか？

はい。Windows はタスクスケジューラ（決まった時刻にプログラムを動かす Windows の機能）に、ダブルクリックで毎日9:00の実行を登録できます。Mac も登録用のスクリプトを用意しています。時刻は変更できます。

ちゃんと動いているか、どうやって分かりますか？

1日1回の「稼働報告」で、変化がない日もサイトごとの最終実行日時・取得件数・状態が届きます。メニューの「監視の状況を確認する」でも、いつでも確認できます。

サイトのデザインが変わったらどうなりますか？

「構造変更の可能性」の通知が届き、その回のデータは比較の基準に使いません。誤った「掲載終了」「価格変動」の通知が大量に届くことはありません。設定（セレクタ）を直してから、通常の監視に戻します。

入力自動化で、同じ商品を二重に登録してしまうことはありませんか？

実行前に CSV 内の重複をチェックし、重複している行は送信しません。また、登録の途中で止まった行は「要確認」にして、再実行しても自動では送信しないようにしています。

本番の前に試せますか？

はい。テスト実行では入力までを行い、登録ボタンは押しません。入力後の画面をスクリーンショットで確認できます。
