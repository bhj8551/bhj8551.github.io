AUTOMATION TOOL DEVELOPMENT

Automating repetitive office work, in a form people can easily check.

I build small, practical tools for non-technical office, accounting and sales staff: copying data out of PDF invoices, sorting inquiry emails, checking competitor prices, and entering data into admin screens. Results come with cross-checks and “needs review” flags, so the final check stays with a person.

TOOLS

Three working tools

Each tool runs today on fictional demo data and is adapted to the client’s documents, notification channels or target screens.

Document Data Extractor

PDF / Excel / CSV → one-row-per-record CSV + review workbook

  • Reads invoices, order lists and delivery notes from PDF using character coordinates, so table columns stay in order
  • Merges Excel/CSV files with different column names and layouts
  • Normalizes Japanese era dates, full-width characters, company suffixes and amounts (original values are kept)
  • Cross-checks totals, line items, duplicates and invoice registration number format; only rows that fail are flagged “needs review” in yellow
  • Desktop app for Windows / Mac; no internet connection needed, no data sent outside

Measured on fictional sample documents (field-level accuracy against ground truth):

  • Round 1 — dev set: 99.9–100.0%; holdout set (layout variations, evaluated once at the end): 100.0% for all four document types
  • Round 2 — holdout2 (25 files; pages without repeated headers, two-line headers, combined delivery note/invoice): 100.0% for all four types, 13/13 seeded anomalies flagged, 0 misreads without a flag

Measured on fictional sample documents. Accuracy on your own documents is checked in a free sample test before quoting.

AI Inquiry Assistant

Gmail / Google Forms + generative AI, as a Google Apps Script template

  • Classifies inquiries, sets urgency, summarizes them and extracts deadlines; vague deadlines (“sometime next week”) are flagged for review
  • Masks emails, phone numbers, addresses, card numbers and sender names before anything is sent to the AI
  • Notifies the person in charge via Slack, Chatwork, email, LINE or Google Chat
  • Creates Gmail reply drafts only; auto-send is off by default
  • Works with Claude, OpenAI or Gemini; falls back to keyword rules if the AI call fails; daily reminders and reports

AI output is not guaranteed to be 100% accurate, and pattern-based masking cannot catch every piece of personal data. A person makes the final decision and sends the reply.

Details (Japanese): AI Inquiry Assistant

Web Monitor & Form Auto-fill

Scheduled price / stock / new-item checks + CSV-to-admin-screen entry (RPA)

  • Detects new items, removed items, price and stock changes; color-coded Excel with trend charts; notifies only when something changed
  • Detects likely site-structure changes and does not use that run as the comparison baseline, so wrong data does not pile up
  • Respects robots.txt and keeps at least 1 second between requests to external sites
  • Fills admin screens from CSV rows marked as pending, writes results back to the CSV, checks for duplicates, supports dry runs
  • Uses the Edge or Chrome already installed on the PC; Windows / macOS

APPROACH

Built for what happens after automation

Cross-checks and “needs review” flags

Subtotal + tax = total, quantity × unit price = amount, duplicates and empty required fields are checked automatically, so staff only re-check flagged rows.

Personal data masked before AI; humans decide

Personal data is replaced with tokens such as [メール1] before it reaches the AI provider. Replies stay as drafts until a person sends them.

No silent failures on site redesigns

A sudden drop in item count or missing required fields triggers a “possible structure change” alert instead of recording empty or wrong values.

Free sample check before a quote

I test with a few of your real files (personal data can be blacked out) and report the results before quoting.

    Fixes for reading errors or operation issues found after delivery.

LIMITS

What I don’t do

  • Bypassing CAPTCHAs, login limits, IP blocks or any other access restriction
  • Scraping that violates a site’s terms of service or robots.txt, or collecting members-only pages without permission
  • Automated purchasing, bidding or reservation grabbing
  • Automating input into systems the client is not authorized to operate
  • Fully automatic email replies as the default way of working
  • Reading scanned (image-only) or handwritten PDFs without an optional OCR setup
